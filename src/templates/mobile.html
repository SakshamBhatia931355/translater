Privacy and this device

Learning activity is stored in the local SQLite database on the PC running this app. A PIN-protected phone link shares the same single-learner profile. The handwriting and translation models run on the PC. If an AI API key is configured, conversation text is sent to that provider; otherwise the guided role-play is scripted.

Speech recognition is provided by the browser or device. It may use a separate platform service. This app does not grade pronunciation.
