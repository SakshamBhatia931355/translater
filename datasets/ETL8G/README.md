# ETL8G (local dataset)

Source: ETL Character Database, AIST (ETL8G). This is a local research/training copy. AIST retains copyright. Use is free under the database Terms of Use; cite the database if publishing results. Do not redistribute the data files. Obtain the official dataset from the ETL Character Database download page.

ETL8G contains handwritten samples for 956 character classes (881 educational kanji and 75 hiragana), 152,960 samples total. The G-type record size is 8,199 bytes; image data is 128×127 pixels at 4 bits per pixel. The archive is verified against the published MD5 before it is used.

Archive and extracted data will be stored in this folder. The project code will provide the local extraction/conversion step for training.

Reference: Electrotechnical Laboratory, Japanese Technical Committee for Optical Character Recognition, ETL Character Database, 1973–1984.
